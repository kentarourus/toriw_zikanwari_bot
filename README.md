# 2-3 時間割

Google スプレッドシートの「時間割」「連絡」を表示する、スマートフォン対応の閲覧アプリです。

`dist` が配信対象です。ページを開いたときと「更新」を押したときに元のシートを読み取ります。元のシートへの書き込みは行いません。取得に失敗したときは取得日時付きで最後のデータを表示します。初回の予備データは `dist/snapshot.json` です。

シートの既存レイアウトに合わせて行・列を読み取るため、配置を変更した場合は `dist/app.js` の対応も必要です。XLSX形式で値・文字色・背景色を同時に取得し、凡例C15:G15に対応する色には変更ラベルを付けます。通常の交互の背景色は変更扱いにしません。「授業時間変更」の月とURLは、連絡シートのD2から自動で更新します。

ローカル起動: `python -m http.server 5173 --directory dist`

データの検証: `npm test`

色読み取りモジュールのビルド: `npm run build`

予備データ更新: `node verify-colors.mjs --snapshot`
