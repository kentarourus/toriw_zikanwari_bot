# 2-3 時間割

Google スプレッドシートの「時間割」「連絡」を表示する、スマートフォン対応の閲覧アプリです。

`dist` が配信対象です。ページを開いたときと「更新」を押したときに元のシートを読み取ります。元のシートへの書き込みは行いません。取得に失敗したときは取得日時付きで最後のデータを表示します。初回の予備データは `dist/snapshot.json` です。

シートの既存レイアウトに合わせて行・列を読み取るため、配置を変更した場合は `dist/app.js` の対応も必要です。セルの色による変更情報とリンク先の動的な変更は反映されません。最新の詳細は元のシートで確認できます。

ローカル起動: `python -m http.server 5173 --directory dist`

データの検証: `node verify.mjs`
